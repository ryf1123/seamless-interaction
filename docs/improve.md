# 怎么把效果做上去：按性价比排的清单

**当前最好**：2000 句 + 离散语音 token + EMA + 推理后 SG 滤波
→ SemAcc **76.1 % [73.0, 79.1]**（200 条测试句 / 664 个事件），抖动 4.36× 真值，MPJPE 7.43 cm。

主指标是 SemAcc（随机 7.7 %，真值 100 %）。下面每一条都写清
**成本 / 预期 / 怎么验证 / 依据**，以及**实测结果**。

---

## A. 已验证有效

### A1. 推理后 Savitzky-Golay 滤波（窗口 9 = 300 ms）★ 目前性价比最高

- **成本**：零。后处理，不重训。
- **实测**：抖动 14.17× → **3.84×**（降 73 %），MPJPE 9.53 → **7.40 cm**（降 22 %），
  SemAcc 73.0 % → **75.9 %**。在第二个模型（`audio_a_token`）上完全复现。
  2000 句上配对提升 **+5.8 个百分点 [+2.5, +9.1]**，区间不含 0。
- **代价**：FGD 0.53 → 19.2。其中约 1.3 是指标假象（把真值自己滤一遍也会得到 1.30），
  剩下是真实的分布偏移。
- **限定**：中心窗口有 **150 ms 延迟**，流式场景要改因果滤波。
- **依据**：Seamless Interaction §4.1 对**训练数据**就做过同样的平滑。
- 详见 [`notes/10`](../notes/10-推理后平滑.md)。

### A2. 离散语音 token 条件（而不是 80 维连续 Mel）

- **成本**：零（k-means，几秒）。
- **实测**：同为 5000 步时 FGD **0.39 vs 5.05**（好 13 倍）；SemAcc 无显著差异。
- **限定**：**FGD 在 5000 步远未收敛**（同配置两个 run 是 5.05 和 6.21，同配置 8000 步是 0.53），
  所以这一列读的是**收敛速度**不是最终质量。训久了 Mel 会追上来。
- 详见 [`notes/08`](../notes/08-第三环-语音表示.md)。

### A3. 更大的测试集（400 → 2000 句）

- **成本**：35 秒建数据（TTS 缓存全热）+ 更长训练。
- **实测**：SemAcc 无可测变化，但**置信区间从 ±7.0 收窄到 ±3.5 个百分点**。
- **买到的是结论的可信度，不是模型的精度。** 这也是姊妹项目 sonic / facial 的共同发现。
- 详见 [`notes/13`](../notes/13-数据量.md)。

## B. 已验证无效或有害（**这一节比 A 节长，这本身是结论**）

| 做法 | 成本 | 实测 | 为什么 |
|---|---|---|---|
| 推理参数（CFG × ODE 步数，12 组） | 零 | **完全无效**，抖动全在 14.6–15.1× | 没碰到输出的频谱 |
| 权重 EMA（decay 0.999） | 几乎零 | **无效**：抖动降 2 %，SemAcc −6.6 | 平滑的是权重不是输出；且作用**完全取决于有没有过拟合**（欠训 −6.6 / 过拟合 +5.1 / 数据够多 +0.7） |
| 速度损失 λ_v = 5 | 零 | 抖动降 24 %，SemAcc **−8** | 标量幅度约束，压抖动的同时把手势幅度一起压小 |
| 速度损失 λ_v = 20 | 零 | **两头都输**：SemAcc 37.2 %，抖动反而变差 | 速度项主导梯度，主任务学不好 |
| Huber 重建损失 | 零 | 无额外贡献 | — |
| **加速度先验 λ_acc = 1/10/50** | 零 | **被 A1 严格支配**：λ=50 时抖动 3.69× 但 SemAcc **9.5 %**（随机基线 7.7 %） | 同上，更强的标量约束 |
| 模型内低通核（Hann，噪声未处理） | 一次训练 | **有害**：抖动反涨到 22.74× | flow matching 的样本含一项绕过网络的噪声 ε |
| band-limited（Hann 核 + 低通噪声） | 一次训练 | 抖动 3.75×、FGD 1.075（好），但 SemAcc **−10** | Hann 核会压矮峰；且**只投影输出没投影目标** |
| 训练更久（5000 → 10000 步） | 一次训练 | **有害**：SemAcc 72.3 % → 59.1 %，而 val loss 降 25 % | 320 句训练集上过拟合 |
| 按验证集 SemAcc 选检查点 | 2 % 训练开销 | **选出更差的检查点**（56.9 % vs 62.0 %） | 12 条验证句的 SemAcc 标准误 ±8 个百分点，比要检测的差异还大 |
| 预测低频基（DCT）系数 | — | **写模型之前就否掉了**：K=32（3.18 Hz）时**真值自己**也只有 73.0 % | 真值是平滑的但**不是带限的**（升余弦起收势频谱延伸到 5–6 Hz） |

### 能解释以上全部的一个机制

> **抖动和真实运动，在「加速度幅度」这个标量上是分不开的。**
> λ_acc = 50 时模型的加速度仍是真值的 **2.49 倍**（它从来没被压得比真值更平滑），
> 而 SemAcc 已经塌到随机基线。要分开它们，只能在**频域**上分。

于是：标量约束（λ_v、λ_acc）→ 一起压小；没碰频谱的（EMA、采样参数）→ 无效；
频域操作但用锐截止（band-limited）→ 天花板低；
**Savitzky-Golay 是唯一不用付代价的，因为它就是为「去噪但保住峰的高度和宽度」设计的。**

详见 [`notes/16`](../notes/16-抖动这条线的收尾.md)。

## C. 正在验证

### C1. 把 SG 投影放进训练（`sgproj` 套件）

- **成本**：一次训练。
- **做法**：SG 核同时用在**模型输出、采样噪声、训练目标**三处。
  这是 B 节里 band-limited 那条的正确版本——换掉会压矮峰的 Hann 核，
  并且**把目标也投影**（之前模型要在通带外做永远做不完的无用功）。
- **天花板已量**：SG 窗口 7 滤过的真值 SemAcc **97.8 %**，窗口 9 是 **86.1 %**。
- **预注册预测**见 [`PLAN.md`](../PLAN.md)「第二批」，其中一条是自我否证性的：
  如果 sg7 不高于对照，notes/16 的机制解释要打折。

## D. 未试、但有依据

按性价比排：

### D1. 学出来的基，而不是手工设的截止频率

让模型输出「基 + 系数」，基本身可学。频域的分离由数据决定，
不是我拍脑袋定 3 Hz 还是 5 Hz。成本中等（改表示层），依据是 B 节所有失败都指向
「手工设的频域切分点不对」。

### D2. 级联：先低频骨架，再补细节

Seamless Interaction 的 Face2Body（§4.3）就是这个结构，只不过分的是模态不是频段。
成本高（两个模型），但它是唯一能同时拿到「低频干净」和「高频有细节」的结构。

### D3. 真实数据（BEAT2 / SHOW）

本项目**三次**被「任务设计」绊住（count1/2/3 只差手指、数据几乎确定性、
逐词拼接的语音让音频没有额外贡献）。合成数据能把问题问清楚，
**外部效度只能靠真实数据**。成本：下载 + 适配数据加载，一天。

### D4. 一次主观评测

哪怕只有 10 个人 × 20 对。GENEA Challenge 2022 的结论是
**常规客观指标与主观 human-likeness 的相关性都很差，唯一例外是 FGD**——
而 FGD 在本项目里对频谱变化极其敏感（把真值自己滤一遍就从 0 涨到 1.30），
样本量也只有 40–200。**所有客观指标都已经被证明会骗人，缺的就是这一环。**

### D5. 更大的模型

论文是 12 层 / d=1024，本项目是 6 层 / d=256（7.4 M）。
**放在最后**，因为目前没有任何证据表明瓶颈在容量——
数据量 ×5 都没改善 SemAcc，先扩模型大概率也不会。

## 一句话

**今天试过的训练侧改动全部是中性或负面的，唯一奏效的是一个零成本的后处理步骤。**
这不是运气，是因为抖动的来源在频域，而训练侧的旋钮都是标量。
下一步该改的是**表示**（D1/D2），不是超参。
