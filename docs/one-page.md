# ★ 一页读懂：结论、证据、边界、下一步

在 Mac mini（M4 / 16 GB / 无 CUDA）上从零跑通 **text → gesture**：
文本 → 逐词 TTS（帧级词对齐）→ 条件 → flow-matching DiT → SMPL-H 上半身 43 关节 × 6D → 渲染 → 评测。

**靶心**：text → gesture 里，text 到底贡献了什么？
拆开是两件事——**节奏来自语音的能量包络，语义只能来自文本**。
为了让它可证伪，手势不是拿来的，是**按已知规则造的**（idle + 语音驱动的节拍 + 词触发的语义手势），
所以「去掉文本条件，语义手势命中率塌到多少」是一个能直接量的数。
代价是外部效度，见下面「这个项目问不了什么」。

## 方法纪律（每一条都是被自己坑出来的）

1. **任何指标进主表之前，先量上限和下限。**
   BeatAlign 的可用区间只有 0.14 宽（真值 0.66、同密度随机 0.52），而**所有模型都在 0.80**——
   高于真值，靠撒得密刷分。不量下限根本看不出这个指标已经废了。
   我在批评完别人的指标之后，自己的反馈指标犯了**同一个毛病**（Monadic 组撒 1362 个点头对 187 个真值，拿 0.848 分）。

2. **同测试集上的两组一律做配对检验。**
   非配对区间等于把「两组做的是同一批题目」这个信息扔掉，统计效率差一到两个数量级。
   平滑前后各自区间重叠，配对差是 **+5.8 个百分点 [+2.5, +9.1]**，区间不含 0。

3. **第一个解释通常是错的，每个解释都要能被一个具体的数证伪。**
   本项目被否掉的解释：手指学不动（各关节组误差/幅度比都是 1.0）、模型欠幅（实测过冲 1.09×）、
   合并数数类能救（合并后一点没变）、抖动来自采样噪声或权重噪声（都无效）。

4. **造新数据版本时先量噪声底。**
   同一条件换随机种子 K 次、两两算距离。不知道下限就读不懂模型的分数——第一环就是这么栽的。

5. **把「试过、没用」和成功的改动写同等篇幅。**
   本项目训练侧的每一个想法都是中性或负面的，唯一奏效的是一个零成本的后处理步骤。
   **这个事实本身就是结论。**

6. **长跑进程 + 磁盘缓存 = 要带版本；新加的采样参数要沿所有路径查一遍。**
   前者让两轮训练白跑（FGD 自编码器缓存 shape mismatch，静默崩在评测阶段）；
   后者让一个有效的方法看起来完全失败（`noise_smooth` 没传给 `sample_long`，
   而 38/40 条测试句走的正是那条路径）。

## 这个项目问不了什么

- **外部效度。** 手势是按已知规则造的，语音是逐词拼接的。所以：
  「音频贡献了什么」在这份数据上**无法回答**（包络峰就落在词中间，文本已经给了精确时间）；
  语义手势的密度（覆盖 56% 的帧）比真实数据高一个量级。
- **真人观感。** 全项目没有一次主观评测。GENEA 的结论是常规客观指标与 human-likeness 相关性都很差，
  唯一例外是 FGD——而 FGD 在本项目里对频谱变化极其敏感（把真值自己滤一遍就从 0 涨到 1.30），
  样本量也只有 40–200，**我不信它的绝对值**。
- **规模。** DiT 6 层 / d=256 / 7.4 M 参数，论文是 12 层 / d=1024。
