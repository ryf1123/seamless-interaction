# 13 数据量翻五倍：模型没变好，但结论变可信了

把语料从 400 句扩到 2000 句（`python -m si.dataset 2000 --out data/toy2k`，
TTS 缓存全热的情况下 **35 秒**就建完）：训练 1600 句、验证 200 句、测试 200 句，
162 分钟语音 / 29 万帧。

## 结果

| 配置 | **SemAcc ★** | 95% 区间 | 区间宽度 | FGD | MPJPE | 抖动 / 真值 | 测试句 |
|---|---|---|---|---|---|---|---|
| 400 句 / 5000 步 | 72.3 % | [65.3, 79.3] | 14.0 | 0.392 | 10.50 cm | 15.11× | 40 |
| 2000 句 / 12000 步（原始权重） | 69.6 % | — | — | 0.305 | 10.26 cm | 16.79× | 200 |
| 2000 句 / 12000 步 + EMA | 70.3 % | [66.8, 73.8] | **7.0** | **0.130** | 10.02 cm | 16.43× | 200 |
| **2000 句 + EMA + 推理后 SG 9** | **76.1 %** | **[73.0, 79.1]** | **6.1** | 15.663 | **7.43 cm** | **4.36×** | 200 |

## 三条读法

### 1. 数据量对 SemAcc 没有可测的帮助

70.3 % vs 72.3 %，两个区间大幅重叠。（严格说两者的测试集不同——
`toy2k` 的划分是在 2000 句上重新洗的——所以这个比较只能当粗略参考。）

FGD 倒是明显变好（0.392 → 0.130，全项目最低），说明**更多数据帮的是「动作分布像不像」，
不是「有没有做对手势」**。这和 FGD / SemAcc 一路分道扬镳的其他几次观察一致。

### 2. 真正的收益是置信区间**减半**

```
40 条测试句 / 137 个事件   → 区间宽 14.0 个百分点
200 条测试句 / 664 个事件  → 区间宽  7.0 个百分点
```

这才是这份数据的价值所在。第二环里 `bow` 11.7 % vs `none` 14.6 % 这种比较，
在 40 句的测试集上根本下不了结论（区间 ±7）；在 200 句上就可判了。

> **下一步该做的是把第一环和第二环在 2000 句上重跑**，
> 而不是继续加数据训模型。前者能把「两半信息缺一不可」这个结论钉死，
> 后者已经证明帮不上主指标。

### 3. 推理后平滑再一次给出最大的提升，而且这次是统计显著的

在**同一批 200 条句子**上配对比较：

```
平滑带来的提升 = +5.8 个百分点   95% 区间 [+2.5, +9.1]
```

区间不含 0。加上抖动 16.43× → 4.36×、MPJPE 10.02 → 7.43 cm，
**这是全项目最好的一组数字：SemAcc 76.1 % [73.0, 79.1]**。

代价照旧是 FGD（0.130 → 15.663）。关于这个代价里有多少是指标假象，
见 [`notes/10`](10-推理后平滑.md)。

## 一个附带的观察：EMA 的作用又变了

| 步数 / 数据 | 原始权重 | EMA 0.999 |
|---|---|---|
| 5000 步 / 400 句 | **72.3 %** | 65.7 % |
| 10000 步 / 400 句 | 59.1 % | **64.2 %** |
| 12000 步 / 2000 句 | 69.6 % | **70.3 %** |

- 400 句 + 5000 步（欠训）：EMA 拖后腿 −6.6
- 400 句 + 10000 步（过拟合）：EMA 救回 +5.1
- 2000 句 + 12000 步（数据够多，没怎么过拟合）：EMA 基本中性 +0.7

**「EMA 有没有用」完全取决于有没有过拟合**，没有脱离训练阶段和数据量的答案。
这也解释了为什么文献里对 EMA 的说法看起来总是「默认要开」——
那些设定通常是大数据 + 长训练，EMA 在那个区间里是安全的。

## 复现

```bash
python -m si.dataset 2000 --out data/toy2k
python -m si.train --config configs/flow_body.yaml --name v2_2k \
       --set data=data/toy2k audio_mode=token ema=0.999 steps=12000
python -m si.eval --run runs/v2_2k                                  # EMA 权重
python -m si.eval --run runs/v2_2k --raw --out eval_raw.json        # 原始权重
python -m si.eval --run runs/v2_2k --smooth 9 --out eval_smooth9.json
```
